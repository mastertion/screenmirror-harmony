## 应用介绍

```
扩展屏助手可以把鸿蒙手机或平板变成 Windows 电脑的第二块无线屏幕。两台设备连接同一局域网后，应用会自动搜索可用的电脑，也可以手动输入 IP 直连；连接后电脑桌面画面实时显示在设备上，您可以直接用触摸和键盘操作电脑。

主要功能
· 局域网自动发现，也支持手动输入 IP 直连
· MJPEG 增量画面渲染，支持 15 / 30 / 60 帧与 720P / 1080P / 跟随屏幕
· 电脑端开启访问密码时自动建立加密连接，密码按服务器分别记忆
· 单指触摸与键盘输入回传，顶部工具栏可返回、重连、暂停
· 分辨率、帧率、画质、屏幕方向等设置保存在本机
· 首次启动时展示隐私提示，设置页可查看隐私政策

使用前提：需在 Windows 电脑上安装并启动兼容的扩展屏服务端程序。本应用不提供电脑端程序，不含账号、广告、内购或付费功能；所有设置仅保存在本机，不会上传到任何服务器。
```
